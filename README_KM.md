# Pool Floating Tools (Android)

នេះជា APK project គំរូសម្រាប់ Floating Button លើអេក្រង់ Android។ វាបង្ហាញប៊ូតុងអណ្តែតដែលអាចអូសបាន និង menu តូចសម្រាប់ practice notes ប៉ុណ្ណោះ។ វាមិនកែប្រែ 8 Ball Pool, មិន auto-aim, មិនប៉ះពាល់ game memory/network និងមិនបន្លំការប្រកួតទេ។

## Build
1. បើក project នេះក្នុង Android Studio ឬ IDE ដែលអាច build Gradle Android បាន។
2. ប្រើ JDK 17 និង Android SDK Platform 35។
3. Sync Gradle ហើយ Build > Build APK(s)។
4. ដំឡើង APK លើ Android។
5. បើកកម្មវិធី → Enable Floating Button → អនុញ្ញាត Display over other apps។
6. ចុចប៊ូតុង POOL ដើម្បីបើក/បិទ menu។ អូសប៊ូតុងដើម្បីផ្លាស់ទី។
7. ចុច Stop Floating Button ក្នុងកម្មវិធីដើម្បីបិទវា។

## សុវត្ថិភាព
- អនុញ្ញាត Overlay តែសម្រាប់កម្មវិធីនេះ។
- កុំបញ្ចូល API keys ឬទិន្នន័យសម្ងាត់ក្នុង APK។
- កុំប្រើ overlay ដើម្បីបន្លំ ឬរំខានអ្នកលេងផ្សេង។
