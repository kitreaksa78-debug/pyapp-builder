POOL TRAJECTORY - ANDROID JAVA STARTER
======================================

អ្វីដែលមានក្នុង ZIP
- Android Native Java project
- ស្នើសុំ Overlay permission
- ស្នើសុំ MediaProjection screen-capture permission
- Foreground service សម្រាប់ screen capture
- Floating training panel

អ្វីដែលមិនទាន់មាន
- មិនទាន់សម្គាល់បាល់ដោយ AI/computer vision
- មិនទាន់គណនា Ghost Ball ឬ Bank Shot
- មិនទាន់គូរខ្សែ trajectory លើអេក្រង់
នេះជាគម្រោង starter មិនមែន APK ដែលបាន build រួចទេ។

របៀប Build
1. បើក project folder នេះក្នុង Android Studio ឬ AppForge IDE ដែលគាំទ្រ Gradle Android projects។
2. ប្រើ JDK 17 និង Android SDK Platform 35។
3. Sync Gradle។
4. Build > Build APK(s)។
5. ដំឡើង APK ហើយបើក Pool Trajectory។
6. អនុញ្ញាត Display over other apps និងការចាប់យកអេក្រង់ នៅពេល Android សួរ។

ចំណាំ
- Android បង្ហាញសេចក្តីជូនដំណឹងថាកំពុងចាប់យកអេក្រង់។
- អ្នកអាចបញ្ឈប់ការចាប់យកតាមប្រព័ន្ធ Android។
- មិនមានការកែប្រែ APK ហ្គេម ឬការបញ្ជាបាញ់បាល់ស្វ័យប្រវត្តិទេ។
- Build អាចត្រូវការ internet ដើម្បីទាញយក Gradle/Android dependencies។
