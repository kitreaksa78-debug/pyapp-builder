របៀបប្រើ
  1. សរសេរកូដ JavaScript ក្នុង app.js (និង CSS បើចង់)
  2. មើល ផ្ទាំង app ខាងស្តាំ — render ពីកូដផ្ទាល់ (កែហើយឃើញភ្លាម)
  3. ចុច Build APK → រង់ចាំ ~២–៤ នាទី → ទាញយក APK ដំឡើងលើ Android

APK វេចខ្ចប់ UI ជា Assets/www/index.html ហើយបើកដោយ WebView — ដំណើរការ offline គ្មានត្រូវការ internet ឬ runtime បន្ថែម។
