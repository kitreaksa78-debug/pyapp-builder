របៀបប្រើ
  1. ជ្រើស Java (ណែនាំ) — សរសេរកូដ Java ក្នុងប្រអប់ រួចចុច Build APK
  2. រង់ចាំ ~៣–៥ នាទី (Java) ឬ ~១០–១៥ នាទី (Python)
  3. ចុច ទាញយក APK → ដំឡើងលើទូរស័ព្ទ (ត្រូវបើក «Install unknown apps»)

Java ប្រើ android.app.Activity សង់ UI ដោយកូដ — គ្មាន Python runtime ដូច្នេះ app បើកដើរភ្លាម ហើយអាចហៅ API បាន (មាន INTERNET permission រួចហើយ)។
