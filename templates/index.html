របៀបប្រើ
  1. សរសេរកូដ Java ក្នុងប្រអប់ MainActivity.java
  2. ចុច Build APK → រង់ចាំ ~២–៣ នាទី (Gradle compile Java)
  3. ចុច ទាញយក APK → ដំឡើងលើទូរស័ព្ទ (ត្រូវបើក «Install unknown apps»)

app ប្រើ android.app.Activity សង់ UI ដោយកូដ — គ្មាន runtime បន្ថែម ដូច្នេះបើកដើរភ្លាម ហើយហៅ API បាន (មាន INTERNET permission រួចហើយ)។
