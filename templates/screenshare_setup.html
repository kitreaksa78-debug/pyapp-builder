app Android ដែលម្ចាស់ទូរស័ព្ទចុច «ចាប់ផ្តើម» ហើយយល់ព្រមរាល់ដង — link live ផ្ញើទៅ bot Telegram របស់អ្នក។ session ផុតកំណត់ {{ (ttl // 60) }} នាទី។

  1. ទាញ ZIP ខាងក្រោម → បើក IDE → ទាញ Import ZIP។
  2. ចុច Build APK ក្នុងផ្ទាំង Build → ដំឡើង APK លើទូរស័ព្ទ។

  4. Link live មកដល់ Telegram (ឬបង្ហាញក្នុង notification) → បើកក្នុង browser។
