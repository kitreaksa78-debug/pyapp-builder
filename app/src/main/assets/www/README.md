# 8 Ball Pool Auto Aim Web App

កម្មវិធី Web App សម្រាប់គណនាមុំបាញ់ប៊ីយ៉ាដោយស្វ័យប្រវត្តិ (Auto Aim) ដោយប្រើប្រាស់បច្ចេកទេស **Ghost Ball Method** និង **Vector Mathematics** (គាំទ្រទាំងកុំព្យូទ័រ និងទូរស័ព្ទ Touch Screen)។

## របៀបប្រើប្រាស់ (How to Run)
1. ពន្លា (Extract) ឯកសារ `.zip` នេះ។
2. បើកឯកសារ `index.html` នៅក្នុងកម្មវិធី Browser (Chrome, Edge, Safari ឬ Firefox) ដោយផ្ទាល់ មិនចាំបាច់ដំឡើង Server ឡើយ។
3. ចុចអូសបាល់ស (Cue Ball) ឬបាល់គោល (Object Ball) នៅលើតុប៊ីយ៉ា ដើម្បីមើលបន្ទាត់គណនាមុំបាញ់ និងបន្ទាត់ផ្លាត (Deflection Path) ដោយស្វ័យប្រវត្តិ។
